# horoscopechinois.today

## Product and role

Yongjie Xie independently developed a French-language Chinese-astrology content website aimed at relevant search interests. The supplied record describes an AI-driven workflow for generating and publishing content. It does not record a measured traffic, ranking, or revenue outcome for this project.

## Personal implementation

- Built the site with Next.js 15 App Router, TypeScript, React Server Components, Server Actions, Tailwind CSS v4, and DaisyUI.
- Used Supabase PostgreSQL for database-backed daily content queries.
- Implemented an interactive zodiac finder and a content-publication workflow described in the project record.
- Zustand was documented as future-facing configuration; Chart.js, accounts, email notifications, and added languages were roadmap ideas rather than established shipped features.
